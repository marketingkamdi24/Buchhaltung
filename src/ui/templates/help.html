Schnellstart-Anleitung
1
API-Daten abrufen

Geben Sie Ihren Datumsbereich ein und wählen Sie Plattformen (Amazon, eBay) aus, um Transaktionsdaten von der API herunterzuladen.

2
Shop-Export hochladen

Laden Sie Ihre eBay-Shop-Export-Excel-Datei hoch. Das System gleicht Bestellungen anhand der ORDER_ID ab.

3
Ergebnisse herunterladen

Laden Sie Ihre bearbeitete Datei herunter, in der KD-NR und RG-NR automatisch ausgefüllt wurden.

Schritt 1: API-Daten abrufen
Konfigurationsoptionen
  • Datumsbereich: Geben Sie Daten im Format TT.MM.JJJJ ein (z.B. 21.10.2025)
  • Plattformen: Wählen Sie Amazon und/oder eBay aus, um Daten von diesen Plattformen abzurufen
  • Eigene Herkunft: Fügen Sie bei Bedarf weitere Herkunftsbezeichnungen hinzu (kommagetrennt)
Die API-Daten enthalten ORDER_ID, KUNDENNR (KD-NR) und BELEGNR (RG-NR) zum Abgleich mit Ihren Shop-Exporten.
Schritt 2: Excel verarbeiten
Dateianforderungen
  • Format: Excel-Dateien (.xlsx, .xls) oder CSV
  • Struktur: eBay-Shop-Export-Format mit Bestellnummer in Zeile 11
  • Größe: Bis zu 50MB unterstützt
Was wird verarbeitet
  • Bestellnummer → ORDER_ID abgleichen
  • KD-NR aus KUNDENNR ausfüllen
  • RG-NR aus BELEGNR ausfüllen
  • Gebührensummen berechnen
  • "Andere Gebühr"-Einträge separieren

Stellen Sie sicher, dass Sie Schritt 1 (API-Daten abrufen) abschließen, bevor Sie Ihre Excel-Datei hochladen. Die API-Daten werden in Ihrer Sitzung gespeichert und sind für den Bestellabgleich erforderlich.

  • Stellen Sie sicher, dass der Datumsbereich in Schritt 1 die Daten Ihres Shop-Exports abdeckt
  • Überprüfen Sie, ob die richtigen Plattformen ausgewählt sind
  • Stellen Sie sicher, dass Ihre Excel-Datei die Bestellnummer-Spalte an der erwarteten Stelle hat (Zeile 11)

  • Stellen Sie sicher, dass die Datei im Format .xlsx, .xls oder .csv vorliegt
  • Maximale Dateigröße ist 50MB
  • Überprüfen Sie, ob die Datei nicht beschädigt oder passwortgeschützt ist
